Number system practice

Convert between denary, binary and hexadecimal. All values are between 0 and 255. Each opening or reload generates 32 fresh questions, with 8 questions for each conversion.

One value, three representations

Use 8 bits for binary answers and 2 digits for hexadecimal answers, including leading zeros. You may separate binary into two groups of four bits. Hexadecimal letters can be uppercase or lowercase. Denary answers use ordinary digits. Do not add 0b, 0x or base subscripts to your answers.

Need a reminder? Place values and hexadecimal groups

Binary: the place values, left to right, are:

1286432168421

To find the denary value, add the place values that have a 1. To write a denary number in binary, select the place values that add up to it and use 0 in the other positions.

Hexadecimal: A, B, C, D, E and F represent denary 10, 11, 12, 13, 14 and 15. Each hexadecimal digit represents exactly four binary bits:

0 = 00001 = 00012 = 00103 = 00114 = 01005 = 01016 = 01107 = 01118 = 10009 = 1001A = 1010B = 1011C = 1100D = 1101E = 1110F = 1111

Split an 8-bit binary number into two groups of four, then convert each group separately. For hexadecimal to binary, convert both digits to four bits, then join them. The ranges are 0–255 in denary, 0000 0000–1111 1111 in binary and 00–FF in hexadecimal.
