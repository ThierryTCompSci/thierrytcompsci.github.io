Quick guide: how the five approaches fit together, and when to choose ?

Supervised, unsupervised and reinforcement learning describe the learning signal. Deep learning describes the use of a neural network with many layers. Transfer learning describes reusing a model or learned representations. A statement can support approaches from more than one of these perspectives.

S · Supervised learning

Training examples include known target outputs, such as class labels or numerical values to predict.

U · Unsupervised learning

Patterns, groups or associations are discovered without supplied target outputs for that task.

R · Reinforcement learning

An agent learns from actions in an environment and reward or penalty feedback.

D · Deep learning

A neural network with many layers is explicitly used. An unstated architecture is not enough evidence.

T · Transfer learning

A previously trained model or its learned representations are reused for a new task or setting.

? · Insufficient information

The wording does not establish any of the five approaches. The application alone, such as analysing text, does not identify how a model learns, its architecture or previous training.
