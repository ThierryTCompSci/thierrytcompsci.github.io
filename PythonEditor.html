How this editor works
The page uses Pyodide to run Python locally in a browser worker. No Python installation or execution server is needed. The runtime is downloaded from jsDelivr; this page does not upload your code or responses.
Output appears in the console while the program runs. Each input() call displays an answer box. Type your response and press Enter or Send; your program resumes from that point. Empty responses, repeated questions and input inside functions or loops are supported. End input sends an end-of-file signal, which input() reports as EOFError unless your program handles it.
Interactive input requires WebAssembly JavaScript Promise Integration (JSPI). The page checks the Python runtime’s actual support. Use a recent version of Chrome or Edge if your browser does not support it. Programs that do not ask for input can still run in other compatible browsers.
Stop terminates the worker, even while it is waiting for a response. The time limit is 10 seconds between input requests; time spent answering is not counted. Printed output is limited to 20,000 characters per run, responses to 10,000 characters each, and the displayed transcript to 100,000 characters. Standard input reads other than input() are not connected to the answer box.
Each run starts with fresh Python variables. Python reloads after Stop. The standard library is available; additional package installation and desktop graphical interfaces are not included. CSS, editor logic and worker code are embedded in this file. Python is an external download, so offline use is not guaranteed. Your code draft is saved in this browser when storage is available; console responses are not saved. Download your program to keep a separate copy.
