Parity practice

Count the 1s. Complete the missing parity values. Check your work and keep improving until every answer is correct.

Even parity

The total number of 1s, including the parity bit, must be even. Zero 1s counts as even.

Odd parity

The total number of 1s, including the parity bit, must be odd.

How to complete the exercises

Enter only 0 or 1 in each box. For a parity bit, count across the data row. For a parity byte, count down each data column. The eight answers in the bottom row form the parity byte. In exercises 5 and 6, complete Bit 8 in each data row first, then calculate the last byte down all eight columns. Its bottom-right bit checks the Bit 8 column. For odd parity, the bottom parity byte itself need not have odd row parity.

Check an exercise whenever you are ready. Mistakes count incorrect filled boxes; unanswered boxes are counted separately. Each bit of a parity byte is marked individually. You can retry as often as you like. Use Tab to move between boxes.

Parity can detect an odd number of bit changes in a checked group, but an even number can go undetected. Passing a parity check does not prove that the data is unchanged.
