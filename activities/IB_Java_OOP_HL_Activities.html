HL OOP activities in Java

Independent topic practice for lessons and homework. Teachers can assign a whole topic or an individual task link. Each task has its own Java starter and saved work.

Open the cumulative HL Java project →SL Java topic activities →
Write, run and check Java

The editor includes highlighting, automatic indentation, completion suggestions and Run/Stop. Code tests and concept questions have separate check buttons; both must pass for completion. Topic tasks are independent, while the cumulative project copies a student’s successful code to the next stage.

Serve the pages over HTTP/HTTPS. Internet access is needed to load the Java compiler and runtime; compilation and execution then happen in the browser, without a compilation server. Java 8 is supported. Saved work stays in this browser; each coding page also has backup download/import.
