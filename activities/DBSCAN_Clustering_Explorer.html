Recent steps
    Teaching notes, exact method and limitations

    Core: at least MinPts points within distance ε, including itself. Border: not a core point, but within ε of a core point in a discovered cluster. Noise: not reached from any core point. Noise is not a cluster. Large coloured circles mark examined core points, smaller coloured circles are border points, and dark circles with crosses are current noise. Grey points have not yet been assigned.

    Visible expansion: one point is examined per step. A queue holds neighbours to visit. Core points add their unvisited neighbours to the queue; border points do not. A non-core point visited before any core point reaches it is provisionally marked noise and can later become a border point.

    Order effects: point IDs define visiting order. If a border point can be reached by two different dense regions, the first discovered cluster claims it. Core-region membership remains density-based. No starting centroids or requested K are used.

    Limitations: small ε or large MinPts can leave many points as noise; large ε can join separate groups. A single setting may struggle when groups have very different densities. Scaling the features changes neighbourhoods. This demo uses Euclidean distances in two equally scaled features.

    Data and distances: synthetic layouts are regenerated each time; no labels from their generation are used by the method. Both features have a 0–10 scale. Euclidean distance is used. These small examples illustrate behaviour; they do not prove that one method is always best.

    Method reference: scikit-learn documentation. Calculations are implemented locally in JavaScript; the page does not load this library or send data anywhere.
