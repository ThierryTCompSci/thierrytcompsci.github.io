Teaching notes: metrics and hyperparameter tuning

This page demonstrates binary classification metrics. Rows represent predictions and columns represent actual labels, as shown. Other textbooks and software sometimes transpose this arrangement; the labels determine how to interpret the cells.

Precision and recall focus on the class designated “positive”. Accuracy includes both positive and negative outcomes. F1 is the harmonic mean of precision and recall, expressed here using the equivalent count formula 2TP / (2TP + FP + FN).

Hyperparameters such as K in KNN or maximum depth in a decision tree can change predictions, which changes these counts and scores. Compare candidate settings on validation data or through cross-validation, using metrics appropriate to the problem. Keep a separate test set for final evaluation. Adding dots here illustrates outcomes; it does not train or tune a model.

A high accuracy can be misleading with imbalanced classes. The relative importance of false positives and false negatives depends on the task. F1 ignores true negatives, so it does not describe every aspect of performance.

Zero-denominator conventions vary between software packages. This demonstration displays “Not defined” rather than silently assigning a numerical value. The count form of F1 is used even when the separate precision or recall fraction is undefined.
