↗Straight Line Lab Year 8 Maths

Level 4

Plot two points, then find the equation of their line.

y = mx + c

1. Plot the points

Select the grid intersection for each point. You can plot them in either order.

Use a browser that supports canvas to plot points.

Keyboard controls

Focus the graph, use the arrow keys to move, and press Enter or Space to add or remove a point.

2. Find the equation

Use the two points to calculate m and c. You can enter fractions like 1/2 or decimals like 0.5.

Need a hint?
  • Divide the change in y by the change in x, using the same point order for both.
  • Use either point’s coordinates in c = y − mx.
  • Put your values for m and c into y = mx + c.
