Boolean logic · Build and check

From expression to logic diagram.

Generate a Boolean expression, build its circuit using inputs and logic gates, then check whether its output matches for every input combination.

1. Choose an expression

Operators to include

XNOR is off by default for IGCSE. IB students can include it. Only selected operators appear in generated expressions; operators may repeat. All seven gates remain available for building equivalent circuits.

NOT counts as one operator. Generating a new expression clears the current diagram.

2. Build this expression

Diagram workspace

Click a gate above to add it. Drag its body to move it.
Connect: drag from a green output port to a blue input port, or in the reverse direction. You can also select one port, then the other. Move: drag a symbol’s body. Delete: select a symbol or wire, then press Delete or the button below. Scroll across the workspace on smaller screens. Drag its bottom-right corner to resize the visible area vertically.
Select a symbol or connection
One signal can branch

An input or gate output can feed several other inputs. Each input port accepts one incoming wire. Connecting another output replaces its existing wire.

Names matter

Use the input names shown in the expression. Repeated names on different input symbols represent the same variable. Double-click an input to rename it.

Equivalent circuits count

The checker tests every input combination, rather than requiring one exact arrangement. Complete all connections and remove unused symbols before checking.

Keyboard controls and checking rules

Use Tab to focus a symbol or port. Enter or Space selects it. On a focused symbol, arrow keys move it by 10 units; Shift + arrow moves it by 30. Select two ports with Enter or Space to connect them. Delete or Backspace removes the selected item; Ctrl/Cmd+Z undoes an edit; Escape cancels a selection or unfinished connection.

Each binary gate has two inputs; NOT has one. The output Y is required and can be moved, but not deleted. Feedback loops are not allowed. This activity uses Boolean values only; wires that cross are not automatically connected. The checker reports a differing input combination when a completed diagram is not equivalent, without showing a solution diagram.
