One iteration is one assignment followed by one centroid update. The cost is the sum of squared distances from each point to its assigned centroid; lower values mean tighter groups for that run. It is not classification accuracy.

What if the dataset changes?

Add an unlabelled point and rerun clustering to see its influence. Adding or removing a point restarts the algorithm.

The original dataset contains 48 unlabelled points.

1. Initialise

Choose K starting centroids. This demo uses a seeded K-means++ method that favours well-spaced starting points.

2. Assign

Compare feature values using straight-line distance. Assign every point to its nearest centroid.

3. Move and repeat

Move each centroid to the mean X and Y of its group. Repeat assignment and movement until the groups and centroids stop changing.

Teaching notes and modelling choices

Try: run with K = 1, 3 and 5. Does a larger K always produce more useful groups? With K = 4 or 5, try new starting centroids. Can the group boundaries or final cost differ? Add an isolated point and observe how it affects a centroid.

Why unsupervised? the input has feature values but no supplied target labels. C1, C2, etc. identify the algorithm’s groups, not categories such as “correct”, “incorrect”, “Class A” or “Class B”. A person may interpret the resulting groups afterwards.

What each half-step shows: after assignment, the colours show the nearest centroid. After movement, the centroids have changed but the colours still represent the previous assignment. The next Assign step checks whether memberships should change. The page keeps these stages separate so the reasoning is visible.

Cost: within-cluster sum of squares (WCSS, or inertia) = Σ distance(point, assigned centroid)². The sum is undefined here before the first assignment. Assignment and mean updates should not increase this cost for a fixed dataset. A lower cost at a larger K does not by itself show that the grouping is more meaningful.

Initialization and special cases: a seeded random process chooses the first centre, then selects subsequent centres with probability proportional to squared distance from the nearest existing centre. Equal distances use the lower group number. If a group becomes empty, this demo keeps its centroid in place and shows its zero membership. K is the requested number of centroids; an empty group is possible. Runs stop at convergence or 100 iterations.

Limitations: K-means favours compact groups measured by Euclidean distance. It can be affected by outliers, feature scales and starting positions, and does not guarantee the globally best grouping. Both displayed features share a 0–10 scale. This synthetic dataset was designed for explanation.

Method reference: scikit-learn: K-means clustering. This page implements the calculations directly in JavaScript.
