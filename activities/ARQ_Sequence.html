ARQ: put the exchange in order

Who sends what, and when? Rebuild three automatic repeat query exchanges, from the first transmission to successful delivery.

Methods of error detection · Topic 2.2

Your mission

Choose a situation, then arrange its action cards from first to last. Each situation begins with the sender transmitting data and starting a timer.

ACK · Positive acknowledgementNAK · Negative acknowledgementTime-out · Waiting time has expired

ARQ uses acknowledgements and time-outs to trigger retransmission. The receiver uses an error-detection method to check data that arrives. For these exercises, assume each check correctly identifies the stated error and the retransmission succeeds.

Arrange the actions

Successful delivery

The data arrives, no error is detected, and the positive acknowledgement arrives before the timer expires. Start with the initial transmission and finish when the sender confirms success.

Drag a card onto the position you want, or use its ↑ and ↓ buttons. On a touchscreen, use the arrow buttons. With a keyboard, use Tab then Enter or Space. The numbered circles show the current order.

    Each card shows whether it is in the correct position. Adjust the order and check again. The correct sequence is not revealed.
