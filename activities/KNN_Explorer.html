Teaching notes and modelling choices

Try these questions: What happens when K = 1? Can you find a place where increasing K changes the predicted label? What happens when K is the size of the whole dataset? Why can an even K lead to a tie with two classes?

Same-scale features: both axes use the range 0–10 and the same visual scale, so the circle represents Euclidean distance accurately. With real data, features measured on very different scales often need scaling before distances are compared.

Ties: a tied class vote is displayed as “Tied vote”, rather than assigning a label arbitrarily. If the Kth and next point have the same distance, their original dataset order determines which is selected. Distances are calculated at full precision; the table rounds them to three decimal places.

Region overlay: the optional background colours show predictions on a coarse grid. They illustrate how the same classifier would label other locations; the displayed region edges are approximate.

Method reference: scikit-learn: nearest-neighbour classification. This page implements the calculations directly in JavaScript and does not load an external machine-learning library.
