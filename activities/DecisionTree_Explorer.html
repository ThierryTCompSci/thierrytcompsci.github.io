    1. Try possible questions

    For each feature, try cut-off values halfway between distinct training values. Each question divides the current training points into two groups.

    2. Prefer purer groups

    Select the allowed split with the lowest weighted child Gini. Repeat within each child, stopping at the depth limit, a pure group or when no useful split is possible.

    3. Route a new point

    Apply the learned questions without using a known label for the new point. Its leaf supplies the prediction.

    Teaching notes and modelling choices

    Explore: compare depth 1, 2 and 4. Which extra questions appear? Move the query across a split boundary. Why can several locations receive the same label? Raise the minimum leaf size and observe which small groups can no longer be separated.

    Gini impurity: Gini = 1 − p(A)² − p(B)². A pure node has Gini 0; an evenly mixed two-class node has Gini 0.5. A candidate’s child Gini is the average of its two children’s impurities, weighted by their numbers of training points.

    Deterministic training: this is a small, greedy, binary classification tree using numerical feature tests, in the style of CART. It checks midpoint thresholds, considers X before Y when scores tie, and then favours the lower threshold. A split must reduce impurity. Maximum depth limits the number of decisions on any path. Tied leaf votes remain visibly tied rather than being assigned an arbitrary class.

    Training versus generalisation: the displayed training accuracy measures how well the tree labels the same 32 points used to build it. A deeper tree can fit these examples more closely, but this does not establish better performance on unseen data. There is no held-out test set in this demonstration.

    Method reference: scikit-learn: decision trees. The training, predictions and diagrams here are implemented directly in JavaScript.
