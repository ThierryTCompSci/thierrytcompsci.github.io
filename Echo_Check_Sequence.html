Echo check: put the steps in order

Rebuild an echo check. Identify what the receiver sends back and what the original sender compares.

Error checking · Data transmission

Before you start

In an echo check, the receiver sends the data it received back to the original sender. The original sender compares that echo with its retained copy. No checksum calculation is required.

Checks a transmission by returning the received data. It does not use a check digit or calculate a checksum.

Your task

Restore the correct sequence

Start before the first transmission. Finish with the original sender’s comparison and decision. Assume that a complete echoed block arrives back at the sender.

Drag a card onto the position you want it to occupy, or use its ↑ and ↓ buttons. On a touchscreen, use the arrow buttons. Use Tab and Enter or Space to operate the buttons with a keyboard. The numbered circles show current positions.

    Feedback appears on every card. You can move steps and check again.

    Try the sequence again

    Shuffle steps clears the feedback and puts the same process in a different order.
