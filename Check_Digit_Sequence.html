IGCSE Computer Science · Data transmission

Check digit: put the steps in order

Rebuild the complete life cycle of a code with a check digit, from creating the original code to checking a later entry.

Error checking · Data entry

Before you start

A check digit is calculated from the other digits of a code and added to it. During data entry, the system uses the agreed rule to check the entered code. Examples include book identifiers and product codes; their calculation rules can differ.

Checks data entry. It is not a method for automatically correcting a code or for proving that a transmission is unchanged.

Your task

Restore the correct sequence

Start when the original identifier is created, before its check digit exists. Then follow a later entry of that code into a computer. Use the method described here: recalculate the expected check digit and compare it with the entered check digit.

Drag a card onto the position you want it to occupy, or use its ↑ and ↓ buttons. On a touchscreen, use the arrow buttons. Use Tab and Enter or Space to operate the buttons with a keyboard. The numbered circles show current positions.

    Feedback appears on every card. You can move steps and check again.

    Try the sequence again

    Shuffle steps clears the feedback and puts the same process in a different order.
