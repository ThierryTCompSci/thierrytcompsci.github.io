Important: This activity models modern TLS using an ephemeral Diffie-Hellman-style key exchange. Each side creates an ephemeral private key and corresponding public key. They exchange public values and independently derive the same shared secret. The server's certificate/private signing key is used for authentication, not sent to the client and not directly used as the shared secret.
Learning focus: public/private key use, authentication and shared-secret establishment in TLS.
