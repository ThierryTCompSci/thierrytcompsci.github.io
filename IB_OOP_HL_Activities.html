IB Computer Science / OOP / Independent classroom activities

HL OOP activities

Topic-based practice for lessons and homework. Open a topic, or use an individual task link to assign precisely the exercise you want. Students may complete tasks in any order.

For teachers and students

Each task supplies its own starter code, with any needed base classes or fixtures. It does not copy a previous task’s solution. Code and concept answers have separate check buttons, and both must pass to record that task as completed. Saved progress is specific to each topic page.

Python executes locally in the browser; an internet connection is needed to load its runtime. The editor includes highlighting, indentation and Run/Stop controls. Backups can transfer work to another computer.
