01 / SEND

Five launches, eight bits each

Each byte launches all eight bits together. B1 to B5 use distinct colours and labels.

02 / TRAVEL

Late bits meet the next byte

If skew exceeds the gap between launches, a fast wire can deliver B2 before a slow wire delivers B1. Bits never overtake on the same wire.

03 / RECEIVE

A mixture is not a complete byte

The receiver shows the latest value and source byte on each wire. Reduce skew or increase the launch gap to create a shared stable interval.

Teaching model: motion and delays are exaggerated; time is in arbitrary units. Bits represent electrical signals, not objects. Data wires only; clock, ground and framing are omitted.
