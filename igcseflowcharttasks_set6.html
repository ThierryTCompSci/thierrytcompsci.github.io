    Symbols and instruction guide

    Oval: START or END. Use one START; you may use more than one END.

    Rectangle: calculations and assignments, for example Total ← Total + Number. Multiple assignments may use separate lines.

    Diamond: one condition, for example Mark >= 50. Connect both Yes and No branches. Do not write IF or THEN.

    Parallelogram: one INPUT Number or OUTPUT Total. Double-click to edit. An input-type choice appears beside the instruction while editing INPUT.

    Variables are created on INPUT or assignment. Names are case insensitive. Assign with ← or <-. Optional DECLARE Number : REAL is supported in a process symbol.

    Use + - * / ^, DIV, MOD, = <> < <= > >= and AND OR NOT. Put text in quotes: OUTPUT "Pass". Boolean values are TRUE and FALSE. Use & to join text.

    Functions: INT(x), ROUND(x, places), LENGTH(text), LCASE(text), UCASE(text). DIV truncates toward zero; MOD uses the remainder with the dividend’s sign. ROUND uses JavaScript’s tie rule (ties toward positive infinity).

    Loops use arrows back to earlier symbols. Do not enter FOR or WHILE statements. Arrays, procedures and files are not supported.

    To connect: press a green handle on the edge of a shape, drag to a destination shape and release. A live arrow follows your pointer and the destination is highlighted. Decisions have separate Yes (right) and No (bottom) handles. Other symbols use the bottom Next handle. End has no output handle. Drop onto empty space or press Escape to cancel. A new connection on the same output replaces the old one.

    Double-click a shape to type its instruction directly inside it. Enter saves, Shift+Enter adds a line, and Escape cancels. Clicking elsewhere also saves. Drag the body of a shape to move it. Select a shape or flowline and click ×, or press Delete, to remove it. Ctrl/Cmd+Z undoes; Ctrl/Cmd+Shift+Z redoes. Keyboard users can focus a shape with Tab, press Enter to edit, and use arrow keys to move it.

    Run highlights the next symbol. Step executes one symbol at a time. Both pause at INPUT until you submit a value. Stop works while waiting. A 5,000-symbol execution limit catches runaway loops.

    Tests check input consumption and output behaviour, allowing different valid designs. Passing the supplied tests is evidence, not a proof for every possible input. Numeric answers allow small floating-point differences.
